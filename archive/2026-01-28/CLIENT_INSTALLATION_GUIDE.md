## 🔄 Getting Updates
When we release updates:
- Simply open the app again in Expo Go
- It will automatically download the latest version

## ❓ Troubleshooting

**App not loading?**
- Make sure you're connected to the internet
- Try closing and reopening Expo Go
- Make sure Expo Go is updated to the latest version
